# Proposed Components (Planning Stage)

## Compute and Control

- ESP32 development boards
- Local gateway (single-board computer or industrial mini-PC)

## Sensing (Candidate)

- Temperature and humidity sensors
- Smoke / air-quality anomaly sensors
- Occupancy and motion sensors
- ToF / distance sensors for passage monitoring

## Communication

- Wi-Fi / LAN for local infrastructure
- ESP-NOW / BLE for short-range low-power links
- LoRa for fallback or extended-range low-throughput telemetry

## Guidance Output

- Programmable LED evacuation signs
- Optional audio-visual alert modules

## Notes

- Component selection will depend on budget, calibration requirements, and deployment constraints.
- Final BOM should be validated against environment and reliability targets.
