# Future Integration Plan

## Phase 1: Instrumented Miniature Testbed

- Build scaled floor model
- Deploy ESP32 nodes in representative zones
- Validate basic sensing + communication loop

## Phase 2: Gateway Intelligence

- Implement local data aggregation at gateway
- Add TinyML-assisted anomaly scoring
- Couple risk engine with route simulation logic

## Phase 3: Dynamic Sign Prototype

- Connect route decisions to physical LED sign outputs
- Validate update latency and readability

## Phase 4: Controlled Validation

- Conduct supervised, non-emergency drills
- Measure route stability and response timing
- Record false positive/negative trend indicators

## Phase 5: Compliance-Oriented Roadmap

- Map relevant fire-safety and building standards
- Prepare documentation for expert safety review
- Plan certification path where applicable

## Critical Disclaimer

This roadmap does **not** imply current certification or deployment readiness for real emergencies.
