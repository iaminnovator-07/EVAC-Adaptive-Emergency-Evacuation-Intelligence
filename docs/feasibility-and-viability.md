# Feasibility and Viability

## Technical Feasibility

The current browser demonstration validates:

- Real-time visual zone state transitions
- Dynamic route recomputation
- Scenario reset and repeatability
- Local/offline simulation behavior

## Deployment Feasibility (Planned)

A phased retrofit model is considered:

1. Pilot on controlled miniature floor model
2. Limited real sensor deployment in non-critical environment
3. Gradual integration with existing safety workflows
4. Controlled drill-based validation

## Constraints

- Sensor reliability and calibration requirements
- Communication reliability in dense building environments
- Human factors in emergency sign interpretation
- Regulatory and certification requirements for life-safety usage

## Viability Outlook

EVAC is viable as an **assistive intelligence layer** if validated incrementally and integrated responsibly with certified building safety systems.
