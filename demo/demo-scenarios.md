# Demo Scenarios

## Scenario 1: Baseline Safe State

- All zones in safe condition
- Route recommendation follows shortest valid exit path

## Scenario 2: Single Hazard Zone

- Trigger one simulated hazard
- Observe zone transition to caution/blocked
- Observe route update accordingly

## Scenario 3: Multi-Zone Escalation

- Activate additional simulated hazard regions
- Observe rerouting and restricted traversal

## Scenario 4: Simulated Network Degradation

- Enable network-failure simulation mode
- Confirm local fallback behavior persists in browser

## Scenario 5: Recovery and Reset

- Clear all hazards
- Validate route normalization and state reset

## Demonstration Guidance

- Emphasize that all hazards and sensor values are simulated.
- Avoid representing the demo as certified emergency software.
